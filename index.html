Tools About

Free cybersecurity tools that never leave your browser.

Generate strong passwords, hashes, encodings and inspect tokens without sending any data to a server. CyberKit is your lightweight, always-on cyber toolbox.

Security note
  • All tools are client-side only.
  • IP lookup uses a public API (ipwho.is) – optional.
  • For learning & defensive use – not for crime.
  • JWT tool does not verify signatures, only decodes.

Tools

All tools run locally in your browser. Optional IP lookups use third-party APIs.

Strong Password Generator

Generator

Create a random password with custom length and character sets. Great for accounts, Wi-Fi and vaults.

16

Base64 Encode / Decode

Encoder

Convert text to and from Base64. Useful for simple data encoding, headers and lab work.

URL-safe Base64

Encoder

Encode or decode text using URL-safe Base64 (Base64URL). Useful for JWT, tokens and URLs.

Base32 Encode / Decode

Encoder

Convert text to and from RFC 4648 Base32. Handy for TOTP secrets and some protocols.

SHA-256 Hash Generator

Hash

Calculate the SHA-256 hash of any text using the browser crypto API. Good for integrity checks and labs.

Multi-hash & HMAC generator

Hash

Compute MD5, SHA-1, SHA-256, SHA-512 and HMAC-SHA256 from a single input.

Hex ⇄ Text Converter

Converter

Convert between hex bytes (e.g. 48 65 6c 6c 6f) and plain text. Handy for payloads and logs.

URL Encode / Decode

Encoder

Safely encode or decode URL parameters. Useful for debugging requests, redirects and web apps.

Client Info / IP Viewer

Inspector

See basic information about your browser, OS, screen and public IP. Everything is read directly from your client.

IP Lookup Tool

Lookup

Get approximate geo / ISP info for an IP or domain using the public ipwho.is API. Data is not 100% accurate.

Subnet / CIDR calculator

Network

Calculate network, broadcast, host range and more from an IPv4 address with CIDR notation.

Unix Timestamp Converter

Time

Convert between Unix timestamps (seconds) and ISO date/time. Great for log analysis and JWT claims.

ROT13 / Caesar Cipher

Cipher

Apply ROT13 or a generic Caesar shift to text. Letters rotate, other characters stay as-is.

13

JWT Header / Payload Decoder

JWT

Decode the header and payload of a JSON Web Token (JWT) using Base64URL. Does not verify signatures.

Random Token / API Key Generator

Generator

Generate random tokens suitable for API keys, secrets or identifiers using the browser crypto API.
